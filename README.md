**blockchain-notes_52** 是一个开放共享的区块链学习知识库，系统整理区块链技术的基础概念、共识机制、智能合约、联盟链平台等核心知识，并配套学习路线与环境搭建指南，帮助初学者建立完整的区块链知识体系。

> 项目命名说明：按照课程要求，项目名称为「自定义名称_学号后两位」，作者学号后两位为 **52**，故命名为 `blockchain-notes_52`。

## 项目背景

区块链作为分布式账本与可信计算的核心技术，是数字经济的重要基础设施。然而初学者往往面临资料分散、概念抽象、缺乏系统学习路径等问题。本项目希望以开源协作的方式，构建一份持续演进、社区共同维护的区块链学习资料。

## 快速开始

1. 克隆本仓库：

```bash
git clone https://github.com/hxy134679/blockchain-notes_52
cd blockchain-notes_52
```

2. 按 [docs/learning-roadmap.md](./docs/learning-roadmap.md) 中的学习路线，从 `notes/` 目录开始阅读。

3. 搭建本地实验环境请参考 [docs/environment-setup.md](./docs/environment-setup.md)。
