# 区块链学习路线图

本路线图面向零基础学习者，分为四个阶段，建议总时长 8~12 周。

## 阶段一：建立认知（第 1~2 周）

- 理解区块链的定义、"分布式账本"与"去中心化"的含义
- 了解区块链发展史：比特币 → 以太坊 → 联盟链 → Web3
- 学习资料：[notes/01-blockchain-overview.md](../notes/01-blockchain-overview.md)

## 阶段二：核心原理（第 3~5 周）

- 哈希函数、非对称加密、默克尔树
- 共识机制：PoW、PoS、PBFT 的原理与取舍
- 学习资料：[notes/02-consensus-mechanisms.md](../notes/02-consensus-mechanisms.md)

## 阶段三：动手实践（第 6~9 周）

- 搭建以太坊开发环境（Remix / Hardhat）
- 编写并部署第一个智能合约（Solidity）
- 学习资料：[notes/03-ethereum-smart-contracts.md](../notes/03-ethereum-smart-contracts.md) 与 [docs/environment-setup.md](./environment-setup.md)

## 阶段四：进阶与选型（第 10~12 周）

- 联盟链：Hyperledger Fabric 架构与 Channel 机制
- 公链与联盟链的选型对比
- 学习资料：[notes/04-hyperledger-fabric.md](../notes/04-hyperledger-fabric.md)

## 学习建议

1. 每完成一个阶段，用自己的话写一篇总结笔记；
2. 通过 Issue 与社区同学讨论疑难问题；
3. 有余力时以 PR 形式把自己的笔记贡献到本仓库。
