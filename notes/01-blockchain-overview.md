# 区块链基础概念

## 1. 什么是区块链

区块链（Blockchain）本质上是一种**分布式账本技术**：数据以"区块"为单位按时间顺序链式串联，通过网络中多个节点共同维护和验证，无需可信第三方即可实现数据的不可篡改与可追溯。

其核心特征可以概括为：

- **去中心化**：账本由全网节点共同维护，不存在单点故障与单点控制；
- **不可篡改**：每个区块包含前一区块的哈希值，改动历史数据会使后续所有区块失效；
- **可追溯**：所有交易记录公开可查，可追溯至创世区块；
- **集体维护**：依靠共识机制保证各节点数据一致。

## 2. 发展历程

| 阶段 | 时间 | 标志事件 | 特征 |
| ---- | ---- | -------- | ---- |
| 区块链 1.0 | 2008-2013 | 中本聪发表比特币白皮书（2008），比特币创世区块诞生（2009） | 数字货币 |
| 区块链 2.0 | 2014-2017 | 以太坊主网上线（2015 年 7 月），引入智能合约 | 可编程金融 |
| 区块链 3.0 | 2018 至今 | 联盟链成熟、产业区块链兴起 | 可编程社会、产业应用 |

## 3. 区块的结构

一个典型的区块包含以下部分：

- **区块头**：版本号、前一区块哈希（Prev-Hash）、默克尔树根（Merkle Root）、时间戳、难度目标、随机数（Nonce）；
- **区块体**：打包的交易列表。

区块之间通过 `Prev-Hash` 相互引用，形成从创世区块出发的链式结构——这正是"链"的由来。

## 4. 核心技术支撑

1. **密码学**：哈希函数保证数据完整性，非对称加密实现数字签名与身份认证；
2. **P2P 网络**：交易与区块在节点间广播、同步；
3. **共识机制**：解决分布式系统中"谁来记账、如何达成一致"的问题；
4. **智能合约**：部署在链上的自动执行程序，是区块链可编程性的基础。

## 5. 延伸思考

- 区块链"去中心化"并非绝对，联盟链场景下更多是"多中心化"；
- "不可篡改"指的是链上数据修改成本极高，而非绝对不可修改；
- 学习区块链应从"信任机器"的视角理解其价值，而不是只关注币价。
